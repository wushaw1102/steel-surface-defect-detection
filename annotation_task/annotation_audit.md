## 手工标注一致性核查

从 test 划分抽出 18 张（逐类 3 张），4 张样例先校准框选粒度（crazing 按裂纹簇切分、inclusion 每条夹杂单独成框），其余 14 张（逐类 2/2/3/2/3/2 张）在看不到原标注的情况下盲标，再逐框比对。
匹配规则：同类且 IoU ≥ 0.50。

| 指标 | 值 |
|---|---|
| 核查图像 | 14 张 |
| 原标注框 / 我标的框 | 33 / 35 |
| 匹配上的框 | 13 |
| 漏标（原有、我没标） | 20 |
| 多标（我标了、原标注没有） | 22 |
| 匹配框平均 IoU | 0.635 |
| 匹配框 IoU 中位数 | 0.558 |
| 按原标注计的召回 | 0.394 |
| 按我的标注计的精度 | 0.371 |
| F1 | 0.382 |

框的切分粒度因人而异（同一片缺陷，一个框还是拆成几个框都对），所以上面这组逐框指标会低估一致性。把两边的框都栅格化成像素掩膜、再算区域重合，就可以把「切法不同」和「真的漏看」分开：

| 区域级指标（与切分粒度无关） | 值 |
|---|---|
| 区域 IoU | 0.579 |
| 原标注区域被覆盖比例 | 0.820 |
| 我标出的区域里属于缺陷的比例 | 0.663 |

逐类匹配数：crazing 1，inclusion 5，patches 4，pitted_surface 0，rolled-in_scale 2，scratches 1
